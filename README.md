# 🚀 AscendAI

### From Classroom to Career.

AscendAI is an AI-powered career development platform designed to help students prepare for placements through an intelligent, all-in-one workspace. It brings together resume building, portfolio creation, AI interview preparation, job application tracking, and career analytics into a seamless experience.

> Empowering students to transform their potential into successful careers.

---

## 🌟 Overview

The placement journey is often scattered across multiple websites and tools. Students use one platform for resumes, another for portfolios, another for interview preparation, and spreadsheets for tracking job applications.

AscendAI solves this problem by providing a unified platform where students can manage every stage of their career journey—from learning and preparation to securing their dream job.

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/yourusername/ascendai.git
```

Move into the project

```bash
cd ascendai
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Open your browser

```
http://localhost:3000
```
